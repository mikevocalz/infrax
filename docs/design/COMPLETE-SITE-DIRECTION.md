# InFraX — complete original-site visual pass

The approved original InFraX is the design baseline. The user's Web Designer Pro pack governs the keep/enhance/remove inventory, application-specific layouts, motion, rendered critique and release checks. The existing homepage is not replaced by a generic dashboard.

## Scope
All 74 registered routes must have a deliberate presentation and be checked at phone, tablet and desktop widths. The public website keeps the four-group Platform / Solutions / Insights / Company header and the original image-led/type-led compositions. Native-first workspace components remain NYC-Tron/React Native with Zustand. Web-specific semantic presentation stays in owned UI adapters. Kinetrell web motion respects reduced motion.

This snapshot is the isolated preview implementation. It preserves existing CMS/auth/database work on the parent branch, does not overwrite that integration, and must not be released as the live product: its API and role selectors deliberately use synthetic fixtures and block database writes, real login, email and submission delivery.

## Source preservation
Original Home, Services, Why InFraX, About, Solutions, Partners and Metrics compositions are carried forward with corrected domain copy and no fake partner directory. Capital retains its review-dossier intent; Execution its numbered process; Platform its modeling environment. Resource, methodology, coverage, glossary, policy, support and authentication pages have explicit designs rather than a shared marketing-card fallback.

The source-sync workflow is branch-specific and restores hash-checked, already-reviewed text into design-preview as normal source files. It does not deploy, merge, provision databases or modify production credentials. Raw source and acceptance evidence are retained in Git rather than only in an ephemeral sandbox. Remaining production-service and actual-device gates are recorded separately and are not satisfied by screenshot checks.

# InFraX public truth gate

This PR neutralizes the old Next.js site while the cross-platform NYC-Tron / Starter Pro replacement is built.

- No synthetic candidates, sources or market intelligence from production API endpoints.
- Website headline ticker contains qualitative educational guidance, not fabricated realtime statistics.
- Homepage demo facilities are explicitly labeled fictional. Query inputs carry forward into scenario form, but actual verification remains required.
- Solutions and Partners remove unrelated SOC marketing and fake partner logos. Actions lead to real contact flow.
- Intelligence feed shows a truthful unavailable state rather than false timestamp/latency. Capital and Execution label sample records explicitly.
- Existing web JSX is **legacy transitional code**, not the new universal UI; the native/semantic replacement lives in Starter Pro PR #21 and NYC-Tron-UI PR #3.

This is not proof of live services, complete forms, privacy compliance or accessible browser QA. Before merging, run TypeScript/Next build and browser verification.
